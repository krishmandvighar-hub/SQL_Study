# SQL Basics Repository

This repository contains my SQL learning journey and practice queries. It covers fundamental SQL concepts with examples, sample datasets, and hands-on exercises.

## Topics Covered

- Database Creation (`CREATE DATABASE`)
- Table Creation (`CREATE TABLE`)
- Data Insertion (`INSERT INTO`)
- Data Retrieval (`SELECT`)
- DISTINCT
- WHERE Clause
- ORDER BY
- AND, OR, NOT Operators
- NULL Values
- UPDATE & DELETE
- Aggregate Functions
  - MIN()
  - MAX()
  - COUNT()
  - SUM()
  - AVG()
- LIKE Operator
- Wildcards
- IN Operator
- BETWEEN Operator
- Aliases
- JOINS
- Customer, Product, and Order Data Analysis

## Datasets Used

- Customers
- Products
- Orders

## Purpose

The purpose of this repository is to build a strong foundation in SQL for Data Analytics and Database Management. All queries are written for practice, learning, and interview preparation.
